# Portfolio Website

A modern, responsive portfolio website built with React, showcasing my professional journey, skills, and projects. 

## Features
- Interactive UI with smooth animations
- Responsive design that works on all devices
- Skills section with categorized technology expertise
- Education timeline with carousel display
- Project showcase section
- Contact information with social media links

## Tech Stack
- React.js
- React Router for navigation
- Bootstrap for carousel component
- CSS3 for styling and animations
- Font Awesome for icons

## Updating content
All text on the site (experience, projects, education, skills, links) lives in `src/data/profile.js`. Edit that one file and the pages update automatically.
